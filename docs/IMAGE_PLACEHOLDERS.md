# Development image placeholders

Catalogue, campaign, and category imagery currently uses third-party
placeholder photography (primarily Unsplash) for local/preview environments.

**Before commercial launch**, replace all development images with:

- Licensed product photography owned or contracted by Aspera or sellers
- Assets stored in owned/CDN storage configured in `next.config`
- Product-specific crops with accurate alt text

Do **not** ship Meesho, competitor marketplace, or unlicensed merchant images.
