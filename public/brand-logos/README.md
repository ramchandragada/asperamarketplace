# Brand logos

Official vector brand marks only.

## Rules
- Ship **original SVG brand marks** (Simple Icons / brand press SVG).
- **Never** invent logos with `<text>`, restyled wordmarks, product-box crops, or AI-redrawn icons.
- If no official mark is available, omit `imageUrl` and let the UI use a monogram — do not fabricate a logo.
- Keep marks on a transparent background with the brand’s official fill colour.
- Homepage “Shop by brand” and the mega-menu brand strip must show **logo only** (no category eyebrow, no caption under the mark).

## Current set
Files in this folder are the only allowed brand logo assets. Add a slug here and to `OFFICIAL_BRAND_LOGOS` in `src/lib/mega-menu.ts` together.
